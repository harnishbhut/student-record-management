Welcome to the Student Record Management System

This portal allows teachers and college administrators to manage basic student records efficiently. You can view all enrolled students, register new admissions, search and filter records, update academic status, and maintain student details.

View Student Records Register New Student

System Features

  • Student Directory: View complete rosters of registered students with ID, full name, email, course, and year.
  • Student Registration: Simple intake form to register new students with instant data validation.
  • Search & Filter: Instantly look up students by their full name or unique Student ID, or filter by course.
  • Profile Details: Inspect individual student academic profiles and admission dates.
  • Edit Records: Update student information while safeguarding against duplicate email registrations.
  • Secure Database: Powered by an SQLite database with parameterized SQL queries to prevent security vulnerabilities.
  • RESTful API: Standard JSON endpoints for external integration and programmatic data access.

Quick Navigation Tips

To get started right away, click on Student Records in the top menu to view all existing students, or click Add Student to create your first record.
